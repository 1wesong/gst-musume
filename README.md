# 감컴무스메

Japan World Cup 3에서 영감을 받은 팬메이드 싱글플레이 말 경주 웹게임입니다.
8마리가 일직선 레인을 달리고, 중간중간 스킬과 필살기, 벌칙 슬롯이 발동하며, 3등까지 골인하면 경주가 끝납니다.
베팅, 멀티플레이, 서버는 없습니다.

## 기술 스택

- Phaser 3 + TypeScript + Vite
- 메뉴성 UI(말 선택, 결과 팝업)는 캔버스 위 HTML/CSS 오버레이
- 서버, DB 없음

## 시작하기

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # 타입 체크 + 프로덕션 빌드 (dist/)
npm run preview    # 빌드 결과 미리보기
```

## 게임 흐름

로딩 → 메인 화면 → 말 선택 → 레인 소개 → 경주 → 결과 팝업

- 15마리 중 8마리가 출전합니다. 랜덤 또는 직접 선택(선택 순서 = 레인 순서)
- 경주 중 일반 스킬(부스트, 넘어짐, 역주행), 필살기, 벌칙 슬롯이 발동합니다
- 결과 팝업에서 1~3등 시상대를 보여 주고, 다시하기 / 메인으로 이동할 수 있습니다

## 프로젝트 구조

| 경로 | 설명 |
| --- | --- |
| `src/config.ts` | 속도, 스킬 확률, 필살기 배율 등 밸런스 수치 |
| `src/data/horses.ts` | 말 15마리 데이터 |
| `src/data/penalties.ts` | 벌칙 슬롯 데이터 |
| `src/data/background.ts` | 배경/메인 화면 에셋 경로 |
| `src/systems/` | 필살기, 벌칙, 트랙 좌표 변환 등 경주 로직 |
| `src/ui/` | 디자인 시스템(`theme.ts`, 컴포넌트, 전환 효과, 컷인) |
| `src/debug/raceSim.ts` | 화면 없는 경주 시뮬레이션 |
| `public/assets/` | 이미지, BGM |

## 에셋

이미지가 없거나 로드되지 않으면 말 색상의 사각형 + 이름 텍스트로 대체됩니다.
이미지와 BGM은 `public/assets/`에 두고 경로를 `src/data/horses.ts`, `src/data/background.ts`에 지정합니다.
Vite `base`가 `./`이므로 GitHub Pages 하위 경로에서도 경로가 깨지지 않습니다.

## 밸런스 시뮬레이션

```bash
npm run balance [횟수]
```

또는 개발 서버에서 `/?debug=sim&n=100`으로 접속하면 화면 없이 시뮬레이션하고 결과를 콘솔에 출력합니다.
목표는 경주 시간 약 30초, 경주당 1위 교체 3~5회, 필살기 발동 경주에서 필살기 말 승률 약 70%입니다.

## 디자인 시스템

e스포츠 / 스포츠 중계 방송 그래픽 콘셉트의 라이트 톤입니다.
색상, 폰트, 크기, 모션은 `src/ui/theme.ts`에서만 정의합니다. 개발 서버의 `/styleguide.html`에서 공통 컴포넌트를 확인할 수 있습니다.
